# 動作検証チェックリスト

Amplify や Lambda を更新した後、検証用の Amplify 環境にデプロイして通す手動チェックです。
単体テストでは検出できない OAuth リダイレクト、認証モード切り替え、AppSync subscription を対象にしています。

前提: `npx ampx sandbox`（または検証ブランチへの Amplify Hosting デプロイ）で構築済みの環境と、
hugo などの静的ページに `main.min.js` を埋め込んだページが 2 つ以上あること。

| # | 操作 | 期待結果 | 結果 |
|---|---|---|---|
| 1 | 未ログインで記事ページを開く | コメント一覧が表示される（IAM 読み取り） | |
| 2 | 「comment with」のアイコンから Cognito ユーザー名・パスワードでログイン | モーダルが閉じ、Send ボタンが出る | |
| 3 | Google でログイン | Hosted UI を経由してログイン状態になる | |
| 4 | LINE でログイン（有効時） | 同上 | |
| 5 | 記事ページ（ルート以外）から OAuth ログイン | ログイン後に同じ記事ページへ戻る | |
| 6 | 名前を入力せずに Send | 「Name is empty.」が表示される | |
| 7 | 本文を入力せずに Send | 「comment is empty.」が表示される | |
| 8 | コメントを投稿 | 一覧の先頭に表示され、名前の先頭文字がアバターになる | |
| 9 | 投稿に返信、その返信に返信 | 3 階層目のコメントに reply ボタンが出ない | |
| 10 | 自分のコメントを編集 | 「(edited)」が付く。他人のコメントには編集・削除ボタンが出ない | |
| 11 | 自分のコメントを削除 | 内容が「(Deleted)」になり、返信は残る | |
| 12 | ハートを押す、もう一度押す | その場で数が増減し、ON/OFF が切り替わる | |
| 13 | 別ブラウザ（ログイン済み）で投稿 | 元のブラウザにリロードなしで反映される | |
| 14 | 「Save Name and Web」を ON にして投稿、リロード | 名前と Web が復元される | |
| 15 | 「Save Name and Web」を OFF にして投稿、リロード | 名前と Web が空になる | |
| 16 | 本文を書きかけでリロード | エディタにフォーカスすると書きかけが復元される | |
| 17 | サインアウト | ログインボタンに戻り、一覧は引き続き読める | |
| 18 | OS をライト／ダークに切り替える | ウィジェットの配色が追従する | |
| 19 | `#blogcomments` に `data-bc-theme="dark"` を付ける | OS の設定に関わらずダーク表示になる | |
